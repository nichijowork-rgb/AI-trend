## 4. 英語の投稿に日本語訳を付けてください（新規）

日本語以外の投稿には、集めるときに日本語訳を付けてください。

- `text_ja`：本文の日本語訳。日本語の投稿には付けない
- `lang`：原文の言語コード（`en` など。任意）
- `text` は原文のままにしてください。URL・@メンション・#ハッシュタグは訳文にもそのまま残してください
- 翻訳はお使いのもの（Claude API の安いモデル、DeepL など）でかまいません。訳せなかった投稿は `text_ja` を省略してください
